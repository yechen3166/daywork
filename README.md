# 新澳汇总（iPhone 桌面 App / GitHub Pages）

## 上传到 GitHub
1. 在 GitHub 新建一个仓库。
2. 将本压缩包解压，把里面的 `index.html`、`manifest.webmanifest`、`service-worker.js`、`icons/` 和 `README.md` 全部上传到仓库根目录，保留文件夹结构。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，点击保存。
5. 等待部署完成，打开 GitHub Pages 提供的 HTTPS 地址。

## 添加到 iPhone 主屏幕
1. 用 iPhone 的 Safari 打开 GitHub Pages HTTPS 地址。
2. 点击分享按钮。
3. 选择“添加到主屏幕”。
4. 名称显示为“新澳汇总”，点击“添加”。

## 一键清空生肖
页面顶部的“一键清空所有已添加生肖”按钮会清除网页、论坛、飞机三个版块中已选的生肖，并清空论坛/飞机自动累计的战绩记录。网页名称、自定义标签、用户名和开奖结果会保留。操作前会二次确认，建议先点“导出备份”。

## 数据保存
页面数据保存在当前设备/浏览器本地。不同设备或浏览器之间不会自动同步，请使用页面里的“导出备份”和“导入备份”迁移数据。
